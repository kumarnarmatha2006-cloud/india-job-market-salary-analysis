# India Job Market Salary Analysis

## Project Overview

This project analyzes job market data in India to understand salary trends, job roles, required skills, locations, and employment patterns.

## Project Objectives

* Analyze salary trends across job roles.
* Compare salaries across different locations in India.
* Explore required skills for different jobs.
* Understand employment types and remote work options.
* Create an interactive Power BI dashboard.

## Tools and Technologies

* Python
* Pandas
* SQL
* Power BI
* Excel

## Dataset Details

* Total Records: 10,000
* Market: India
* Job roles include Data Analyst, Data Scientist, Business Analyst, Software Engineer, and more.
* Dataset fields include job title, company, location, experience, skills, salary, employment type, and remote option.

## Project Workflow

1. Data inspection using Python.
2. Data quality checking and cleaning using Pandas.
3. Data analysis using SQL.
4. Exploratory data analysis.
5. Interactive dashboard development using Power BI.

## Key Analysis

* Average salary by job role.
* Salary comparison by location.
* Job market trends across different roles.
* Skills and employment pattern analysis.

## Dashboard

An interactive Power BI dashboard was developed to present important job market and salary insights.

## Conclusion

This project demonstrates the use of Python, Pandas, SQL, and Power BI to analyze job market data and present meaningful insights through data visualization.
